# huabao-stars

面向华为画报「明星」品类的两个 Codex Skill：

| Skill | 用途 |
|---|---|
| `huabao-star-topic-planner` | 从可验证素材策划新的明星类锁屏选题，输出标题、副标题、落地页、来源、去重和双目标评分。 |
| `huabao-star-headline-refiner` | 优化已有明星类标题或内容梗概，使其对齐华为画报参考表风格；不替代选题策划和事实核验。 |

## 安装

将两个技能目录复制到 Codex 的个人技能目录：

```text
%USERPROFILE%\.codex\skills\
```

重启或刷新 Codex 后，可显式调用：

```text
$huabao-star-topic-planner
$huabao-star-headline-refiner
```

## 参考依据与数据边界

两个技能的写法来自用户提供的以下本地参考表的归纳，而不是逐条复制案例：

- `D:\yiyouliao working\选题参考\明星类标题参考.csv`
- `D:\yiyouliao working\选题参考\明星.csv`

运行时优先读取当前会话提供的最新版素材库、已做标题表和近期已出选题；上列路径仅是当前环境的默认回退位置。公开仓库只保留归纳后的方法论，不包含原始业务 CSV、内部运营数据或候选池。

## 共同规则

- 上架候选必须带实际打开验证过的、可点击的信息源，格式为 `[来源名·文章标题](https://...)`；没有来源仅能作为文案草案，不能标记为可上架。
- 明星常规标题不以具体人名为核心；仅有明确、可核验的热点动态可例外。
- 标题不超过 10 字，优先 7 字；副标题不超过 25 字；疑问句必须带 `？`。
- 禁止绯闻揣测、负面舆情、未经验证的隐私或绝对化夸张。
- 新选题必须完成素材库、已做标题、近期已出选题三方概念级去重；同一概念族不可第三次使用。

## 维护

更新任一技能的 `SKILL.md` 时，同步更新其 `README.md` 和本仓库根 README（如适用），再运行 Skill Creator 的 `quick_validate.py`。推送 GitHub 后，读取 GitHub raw 文件验证关键内容一致。
