# 华为画报明星类选题策划

将可验证的明星素材转成适合华为画报锁屏的**新选题**。交付必须先有事实、画面题眼和来源，再写标题；不要从标题公式反推空洞选题。

## 启动与参考

每次开始先读：

1. `references/star-methodology.md`：明星类策略、公式、红线和评分口径。
2. `references/topic-output-schema.md`：按任务类型选择输出格式。
3. 需要判断标题风格或结构时，再读 `references/style-patterns.md`。

优先读取当前会话中用户指定的最新素材库 CSV、已做标题表、近期已出选题、近周数据与月报。没有其他路径时，当前环境可回退读取：

- `D:\yiyouliao working\选题参考\明星类标题参考.csv`
- `D:\yiyouliao working\选题参考\明星.csv`

这两个文件是风格参考，不是素材库，也不能替代来源和去重数据。

## 必经工作流

### 1. 先判断交付目标

- **批量新选题**：按完整流程，交付可上架候选卡。
- **单条热点策划**：核验具体事件和时效，交付单条候选卡。
- **候选审核**：不强行重写；逐项判断来源、去重、事实、标题和双目标评分。

信息足够时直接执行。缺少素材、已做标题或来源时，明确说明缺口；不能伪造来源、数据或去重结论。

### 2. 素材库优先与事实核验

1. 先从素材库**最近新增**的链接检索；有添加时间字段时按倒序，无日期时按文件后出现的记录视为较晚追加，并说明无法确认精确时间。
2. 实际打开原文，记录来源名、文章标题、URL、核心事实与可用画面题眼。搜索摘要仅是线索，不得标为已验证。
3. 每个拟上架候选至少有一条实际核验的信息源，强制格式：
   ```markdown
   [已验证] [来源名·文章标题](https://...)
   ```
4. 找不到可验证原文时，候选只能标为“素材池 / 待补源”，不能输出为可上架选题或“主推”。

### 3. 原子候选与三方去重

每篇原文只先拆一张原子候选卡：`明星对象 / 核心事实 / 一秒画面 / 叙事角度`。

将候选与以下三类对象做概念级比对：

- 当前用户维护的已做标题表；
- 近期已出选题；
- 当前批次候选及参考表中已高频使用的概念族。

使用指纹：`主体 | 核心事实 | 视觉题眼 | 叙事角度`。标题不同但核心事实、视觉题眼和叙事角度相同，仍算重复；同一概念族不可第三次使用。没有可读取的去重文件时写“去重数据未提供，不能确认”，不可勾选通过。

### 4. 明星类标题与副标题

- 标题：不超过 10 字，优先 7 字；副标题：不超过 25 字。逐字计入汉字、数字、字母和标点。
- 常规标题使用“身份/对象 + 可成像特征或可验证钩子”，不靠具体人名拉点击；仅明确、可验证的热点动态可用人名。
- 一条标题只保留一个钩子：盘点、反差、关系、隐藏身份、成长、互动或热点事件。疑问句必须带 `？`。
- 副标题兑现标题承诺，补充筛选标准、具体事实、名单或画面细节；不复述标题，不用虚构“网友评价”。
- 只能模仿结构与节奏，不照抄参考表标题、名单和句子。

### 5. 双目标评分与红线

按方法论给出独立分数：P 潜力（A）和月报潜力（B）。只有 `A ≥7` 且 `B ≥8` 才标“主推”。

不得输出或推荐：绯闻揣测、恋情/婚姻/亲属等未证实隐私、负面舆情、攻击性比较、虚假营销、未经验证的“最/第一/唯一/全网盛赞”。人物选题聚焦轻科普、作品、职业经历、公开互动或明确热点。

## 输出要求

使用 `references/topic-output-schema.md` 的对应模板。批量产出只给结果和必要检查结论；用户要求策略/数据复核时，再输出“数据依据 → 判断 → 结论”。

每一条可上架候选必须有：标题、副标题、落地页、信息源、概念指纹、去重结论、A/B 分数和红线自检。来源或去重不满足时必须降级并说明原因。
