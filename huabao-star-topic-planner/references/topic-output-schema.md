# 选题输出模板

## 可上架候选

```markdown
### 选题 N：标题（X字）

- 子方向：
- 原文证据：[已验证] [来源名·文章标题](https://...)；已打开时间：
- 核心事实：
- 视觉题眼：
- 概念指纹：主体 | 核心事实 | 视觉题眼 | 叙事角度
- 三方去重：已做标题 / 近期已出 / 本批候选；结论：
- P 潜力：A/10；依据：
- 月报潜力：B/10；依据：
- 结论：主推 / 分发型 / 精品测试

**标题**：
**副标题**：（X字）
**落地页文案**：（150—300字）

**信息源**
- [已验证] [来源名·文章标题](https://...)

**红线自检**
- [x] 标题 ≤10 字，副标题 ≤25 字，问句标点正确
- [x] 标题承诺由正文与来源兑现
- [x] 无负面舆情、绯闻、隐私或绝对化夸大
- [x] 三方概念级去重已完成
```

## 待补源/待去重候选

```markdown
### 素材池：标题草案（不可上架）

- 缺口：待补直接来源 / 待提供已做标题表 / 待补近期已出选题
- 已知事实：
- 可能方向：
- 下一步：
```

不能因为用户只要求“出标题”就把待补源候选伪装成可上架成品。

## 审核结论

按“可上架 / 待补源 / 去重未完成 / 需弱化 / 放弃”分类，每条用一句话说明最关键原因；用户要求复核时再展开数据依据。
