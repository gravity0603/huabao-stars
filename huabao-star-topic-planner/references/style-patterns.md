# 标题与副标题风格模式

这些模式只用于理解结构和节奏，不用于照抄案例。

| 结构 | 标题特征 | 副标题兑现方式 | 适用边界 |
|---|---|---|---|
| 特征盘点 | `盘点 + 特征 + 对象` | N位、筛选标准、1—2例差异 | 特征必须清晰、可成像 |
| 身份归类 | `经历/背景 + 的 + 对象` | 经历事实、转型或反差 | 履历需来源核验 |
| 反差标签 | `印象 + 反差` | 外表/既有印象 vs 真实技能或经历 | 不凭主观评价造反差 |
| 关系揭秘 | `他们 + 关系 + ？` | 说明关系证据，留一处彩蛋 | 只做公开可验证关系 |
| 成长对比 | `对象 + 前后/现状` | 时间线和明确变化 | 不攻击外貌或身材 |
| 视觉题眼 | `部位/单品 + 秘密/攻略` | 作品场景、造型差异或实用点 | 不做纯时尚品牌软广 |
| 热点事件 | `人名 + 动作` | 作品/节目语境 + 事件细节 | 时效、来源、事实三者齐全 |

## 自检问题

1. 不看副标题，标题能否一眼识别对象与钩子？
2. 不看标题，副标题能否解释“为什么值得点”？
3. 是否用了一个可核验事实，而不是一个泛夸词？
4. 是否可能与既有“同对象 + 同钩子 + 同叙事”构成重复？
