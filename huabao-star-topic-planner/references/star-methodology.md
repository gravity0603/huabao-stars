# 明星类选题方法论

## 依据与适用范围

本方法论归纳自用户提供的《明星类标题参考.csv》（119 组标题/副标题）和《明星.csv》（50 组带月份的历史选题）。参考表中标题高度集中在 7 字；副标题历史样本有时超过当前规格，但本 skill 一律执行当前业务硬规则：标题 ≤10 字、副标题 ≤25 字。

适用华为画报“明星”品类中的演员、歌手、爱豆及公开职业动态。它不是娱乐新闻转载器：优先轻科普、公开职业经历、作品/综艺互动、视觉题眼和成长关系。

## 一句话策略

**具体对象 + 可验证的反差、悬念或承诺。**

标题要让读者瞬间识别“讲的是哪类人”，同时获得一个值得点击验证的点。常规选题不让具体人名占据标题；人名放在副标题中兑现事实。热点事件例外，但必须有直接来源。

## 高优先级选题方向

| 方向 | 可用事实锚点 | 标题结构示例 |
|---|---|---|
| 特征标签盘点 | 明确外形、声线、体态、技能、童年照 | `盘点桃花眼男神`、`冷脸萌男星` |
| 归类身份 | 年代、地域、职业训练、赛道、学校 | `99年当红小花`、`学医的男歌手` |
| 反差猎奇 | 外在与实际性格/技能/经历反差 | `甜妹的低音嗓`、`厚唇也绝美！` |
| 关系揭秘 | 可公开验证的同学、队友、亲属、发小 | `他们曾是队友？`、`明星发小大揭秘` |
| 隐藏经历 | 公开履历、退伍、转型、专业背景 | `当过兵的男明星`、`清北毕业的明星` |
| 成长现状 | 童星、减肥、考学、翻红、前后变化 | `童星现状大揭秘`、`男明星减肥前后` |
| 热点动态 | 明确作品、节目、公开视频/采访 | `白鹿咬手臂入戏`（仅热点例外） |

纯造型/穿搭只能在有明确视觉题眼、作品场景或反差时使用；“某某感”“氛围感”“高级感”这类抽象形容不得单独成题。

## 标题公式与副标题兑现

### A. 盘点承诺型

- 标题：`盘点/大赏/图鉴/大揭秘/大公开 + 具体对象或标签`
- 副标题：`盘点N位 + 明确筛选标准 + 1—2个事实例子 + 收尾`
- 适合：特征、身份、成长、视觉题眼。

### B. 归类标签型

- 标题：`年代/地域/圈子/具象标签 + 对象身份`
- 副标题：`N位对象 + 共同归类依据 + 差异点`
- 避免：只有“高颜值”“气质好”等无法成像的标签。

### C. 反差型

- 标题：`既有印象 + 也/却/竟然/不 + 反差`，或直接使用可识别反差标签。
- 副标题：先写反差事实，再点名或补充场景。
- 反差必须能在原文、访谈、作品、视频或公开履历中验证。

### D. 关系/秘密型

- 标题：`他们 + 关系 + ？`、`对象 + 大揭秘`。
- 副标题：解释关系成立的事实，最具意外感的例子放后面。
- 只能写公开且可验证关系，不能借绯闻或私人关系做谜面。

### E. 热点事件型

- 标题：`姓名 + 明确动作/事件`。
- 副标题：作品/节目/视频场景 + 关键细节；不夸大网友反馈。
- 仅时效明确且已经打开源文时采用，热点失效后不作为常驻题。

## 语言节奏

- 直观直白优先于文字双关；一秒读懂优先于文学化表达。
- 常用但需事实支撑的推进词：`盘点、原来、没想到、竟然、藏不住、上榜、反差`。
- `？`只用于真正的问题或悬念；`！`只用于可信的强反差，避免滥用。
- 副标题用事实兑现，不堆“绝美、震撼、封神、全网沸腾”等空泛夸张。

## 评分

### P 潜力 A / 10

对象识别、点击钩子、近期同类表现、标题直觉、时令/分发适配，各 0—2 分。A≥7 才进入分发候选。

### 月报潜力 B / 10

一秒画面、事实信息增量、图像/版权可用性、新鲜差异、月报/栏目适配，各 0—2 分。B≥8 才进入月报候选。

A≥7 且 B≥8：主推；A≥7 且 B<8：分发型；A<7 且 B≥8：精品测试；其余放弃或补证。

## 红线与降级

- 无实际打开的来源：`待补源`，不能上架。
- 无素材库/已做标题/近期已出选题：`去重未完成`，不能宣称不重复。
- 负面舆情、隐私、绯闻、未经证实关系：直接放弃。
- 事实不足：宁可输出“需补证”，不要用标题公式补出不存在的卖点。
