# huabao-star-topic-planner

用于把明星类可验证素材策划成华为画报锁屏新选题。它处理“从素材到选题”的完整链路：素材库优先、事实核验、三方概念去重、标题/副标题、落地页及双目标评分。

## 何时调用

- “从这些链接出 5 个女明星选题。”
- “这个综艺热点适合做华为画报明星选题吗？”
- “审核这批明星候选题的来源、去重和标题。”

已有标题或内容只需要优化措辞时，请用 `$huabao-star-headline-refiner`。

## 输入建议

提供品类方向、数量、素材库链接/CSV、已做标题或近期已出选题。技能会优先处理素材库最近新增链接；若没有来源或去重材料，会如实降级，不伪造“主推”结论。

## 输出

可上架候选包含标题（≤10 字）、副标题（≤25 字）、落地页、可点击已验证来源、概念指纹、去重结论以及 P/月报潜力评分。标题风格来自用户提供的本地明星参考 CSV 的归纳，不复制原始表格。
