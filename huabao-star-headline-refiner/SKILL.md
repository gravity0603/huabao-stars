# 华为画报明星类标题优化

把用户已有的标题、标题副标题对或内容梗概，改成风格对齐华为画报明星参考表的标题与副标题。只优化表达和结构，**不凭空新增人物、事件、数字、作品、关系或结论**。

## 启动与边界

先读 `references/style-guide.md`；需要执行审核时再读 `references/review-checklist.md`。

- **本 skill 做**：标题精炼、补写副标题、批量备选、字数压缩、风格审核。
- **本 skill 不做**：从外部素材发掘新选题、完整来源核验、三方去重、落地页和 A/B 评分。此类任务使用 `huabao-star-topic-planner`。
- 用户未提供来源时，仍可交付“文字优化草案”，但必须明确其**未核验、不可直接作为上架选题**；需要上架版本时请转交选题 skill 补源与去重。

## 任务类型

1. **纯改标题**：保留事实边界，输出更短、更像参考表的标题；若用户只要标题，不强塞副标题。
2. **标题 + 副标题**：标题放钩子，副标题兑现事实、场景或名单。
3. **从内容梗概提炼**：只从用户给出的事实中提取对象、事件和反差，不扩展事实。
4. **多版本**：按用户数量输出；未指定时给 5 个结构明显不同的版本。
5. **审核**：判断“可用 / 需弱化 / 需核验”，说明具体问题并给可直接替换稿。

## 改写步骤

1. **锁定不可改的事实**：对象身份、已给的人名、作品/节目、事件、数字和时效；没有来源的事实标为未核验。
2. **挑一个主钩子**：盘点、身份、反差、关系、成长、互动或热点事件中只选一个，不能堆砌。
3. **映射到句式**：参照风格指南的结构，优先“具体对象 + 可成像标签/事实”。常规标题以身份标签替代具体人名；有清晰热点事件才保留人名。
4. **写副标题**：用已知事实解释标题，避免同义重复和空泛评价。无法提供事实支撑时，不补“网友”“全网”“最”等夸大词。
5. **逐条自检**：标题≤10字、优先7字；副标题≤25字；疑问句用`？`；自然语序；无绯闻、负面舆情、隐私或虚假承诺。

## 强制风格规则

- 直观直白优先于双关和抽象氛围词。
- `女星/男星/小生/小花/爱豆/歌手/演员`等身份标签优先，避免标题只有泛称“明星”。
- “清冷感、氛围感、高级感、绝美”等不能单独构成钩子；必须转为可见特征、明确事件或有信息增量的角度。
- 引号仅点出一个必要的具象热词或标签；疑问标题必须带问号。
- 不未经核验地加“最、第一、唯一、全网盛赞、封神”等结论。

## 输出

默认给“推荐版 + 备选版”，简洁优先。用户要求多个版本时标注结构类型，避免同批标题只换同义词。

使用 `references/review-checklist.md` 的审核格式。对于没有来源的输入，在输出末尾固定注明：`核验状态：用户未提供来源；以上为文字优化草案，不可直接上架。`
