# huabao-star-headline-refiner

用于优化华为画报明星类已有标题、副标题或内容梗概，使其更贴近参考表的短、直观、信息明确的风格。

## 何时调用

- “把这个标题压到 7 字。”
- “按明星类参考表风格重写标题和副标题。”
- “给这条梗概 5 个不同方向的标题。”
- “审核这些明星标题哪里不合规。”

从素材找选题、核验来源、做去重和评分时，请用 `$huabao-star-topic-planner`。

## 输出边界

这个 skill 不新增事实。没有来源的输入可以优化成文字草案，但必须标注“未核验，不可直接上架”；需形成上架候选时，转由选题 skill 补齐来源和去重。

## 格式

标题不超过 10 字，优先 7 字；副标题不超过 25 字；疑问句使用 `？`。常规标题以“身份 + 特征/事实钩子”为主，不靠具体人名和空泛形容词引流。

## 维护

与 `SKILL.md` 同步维护。修改后使用 Skill Creator 的 `quick_validate.py` 进行验证。
