# 明星类标题与副标题风格指南

## 目标节奏

风格参考来自用户提供的两张明星 CSV 的归纳：标题普遍短、对象明确、钩子单一；大量标题落在 7 字附近。当前执行规格为标题 ≤10 字、副标题 ≤25 字。

标题负责点击钩子，副标题负责兑现。不要把同一句话拆成两半，也不要让副标题只有形容词堆砌。

## 可选结构

| 结构 | 标题特征 | 副标题写法 |
|---|---|---|
| 盘点型 | `盘点 + 特征 + 对象` | N位对象 + 筛选标准 + 具体差异 |
| 身份型 | `经历/身份 + 的 + 对象` | 经历事实 + 反差或转型信息 |
| 反差型 | `可识别印象 + 反差` | “外表/原本印象 + 实则 + 事实” |
| 关系型 | `他们 + 关系 + ？` | 关系证据 + 最意外的例子 |
| 成长型 | `对象 + 现状/前后` | 时间线 + 明确变化 |
| 互动型 | `外号/眼力/挑战 + 对象` | 线索罗列 + 互动问题 |
| 热点型 | `姓名 + 动作/事件` | 作品/节目语境 + 细节 |

## 表达优先级

1. 具体对象：男星、女星、小花、歌手、演员等。
2. 可成像特征：桃花眼、童年照、低音嗓、证件照、外号、运动技能等。
3. 可验证反差：冷脸却软萌、甜妹却低音、演员曾是某职业等。
4. 轻量悬念：原来、竟然、没想到、都是咋来的？

## 常见问题与修法

| 原问题 | 修法 |
|---|---|
| “某女星气质很高级” | 改为有事实或可见标签的对象；若没有，不强行起题。 |
| 标题有两个以上卖点 | 选一个最能成像的钩子，其余放副标题。 |
| 副标题复述标题 | 加筛选标准、具体事实、场景或名单。 |
| 人名堆在标题 | 常规题换成身份标签；把人名放副标题。 |
| 问句无问号 | 加 `？`，或改为陈述句。 |
| “全网、最、封神” | 无来源一律删除或弱化。 |

## 参考表的可模仿之处

- 短：用 7 字左右完成对象与钩子。
- 直：让读者一秒理解讨论的明星类型和信息差。
- 实：副标题含真实的经历、作品、关系、数字或场景。
- 有轻微情绪：可用“原来、竟然、没想到”，但不夸大、不造谣。
